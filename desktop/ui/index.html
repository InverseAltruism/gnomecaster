Find World of Warcraft

Gnomecaster adds a small addon to your game folder.

World of Warcraft wasn't found automatically. Choose its folder: the one that contains _retail_ or _classic_.

Install the addon

This copies Gnomecaster into Interface\AddOns.

Connect an AI

Gnomecaster asks an AI model to answer your questions. With OpenRouter one account reaches many models; a typical question costs less than a tenth of a cent.

Finish signing in in your browser. This window updates when you're done.

You're set

Start World of Warcraft, then type /gc in chat, or bind a key under Options, Keybindings, AddOns, Gnomecaster.

Keep this app running while you play. Closing the window keeps it in the system tray.
